ELI5 Pricing Guide

No confusion. Here is how pricing works.

The Build-A-Bong event has a base price, then guests can choose optional upgrades. Think of it like ordering food: everyone starts with the main plate, then they can add extras if they want a bigger or fancier build.

Show Me Examples See Upgrade Menu

The easiest way to understand it:

Base Build + Optional Upgrades = Your Total

Base builds start at $40–$60. This gets the guest into the event and gives them a complete build experience.
Upgrades are optional. Ash catchers, carb caps, premium bowls, bangers, pearls, and tools cost extra only if the guest chooses them.
Dual-use rig builds start around $80–$85. That means a basic build upgraded with a banger and carb cap.
Premium dual-use builds are usually $90–$95. That means a nicer base, premium quartz banger, and one of the best carb caps.
Step 1

Everybody starts with a base build.

The base build is the starting price for the event. It covers the hands-on build experience, the standard setup, guidance, and the guest leaving with a finished piece.

If someone only wants the regular Build-A-Bong experience, they usually pay somewhere between $40 and $60. That is the starting price before any fancy extras.

The base build is the main price. Upgrades are like add-ons. A guest can keep their build simple, or they can add parts to make it bigger, cuter, or more premium.

For Hosts

How to explain it to your group.

If guests pay individually

Tell guests: “The event starts at $40–$60 per person. You can keep your build basic or bring extra money for upgrades.”

If the host pays as a group

Pick the base level you want covered for everyone. Guests can still pay separately for optional upgrades if you allow it.

If it is a business pop-up

Promote the base price clearly, then list upgrades as optional at the table so customers understand the full range.

FAQ

Pricing questions answered before they ask.

Do I have to upgrade?

No. Upgrades are optional. The base build is enough to participate in the event.

Why does the price say $40–$60?

Because different events may use different base pieces, themes, guest counts, and setup needs.

What is a dual-use rig build?

It is a compatible base build upgraded with a banger and carb cap so it can be built toward a concentrate-ready setup.

Why is the dual-use rig $80–$85?

Because it adds a banger and carb cap to the base build. The rounded package price keeps the math simple.

Why is the premium one $90–$95?

Because it uses a nicer base, a premium quartz banger, and one of the best carb caps available at the event.

Can prices change?

Yes, based on inventory, travel, theme, guest count, and special requests. The published ranges help guests plan before booking.
