# Build-A-Bong SEO Implementation — 20 Added Tactics

This package restores the homepage direction around the original pitch: **Partner with us for a free show**, while adding search discoverability for Build-A-Bong, how to build a bong, Mississippi events, and event planner booking intent.

## 20 implemented SEO tactics

1. **Primary title tag rewritten around intent**
   - Homepage title targets: partner with us, free Build-A-Bong show, Mississippi, Pixie's Pantry events.

2. **Search-focused meta description**
   - Includes free show, Build-A-Bong event, Mississippi, event planner, dispensary pop-ups, private parties, and themed workshops.

3. **Heavy but relevant keyword metadata**
   - Includes 25 high-intent direct phrases without relying on keywords alone.

4. **Canonical URL added**
   - Points homepage authority to `https://buildabong.pixiespantryshop.com/`.

5. **Open Graph metadata added**
   - Better previews when shared on Facebook, Instagram messages, texts, and other platforms.

6. **Twitter/X card metadata added**
   - Better preview title, description, and image.

7. **Geo metadata for Mississippi**
   - Added `geo.region`, `geo.placename`, and ICBM coordinates to strengthen Mississippi relevance.

8. **Organization schema**
   - Defines Pixie's Pantry as the parent brand.

9. **LocalBusiness schema**
   - Defines Build-A-Bong Events as a local Mississippi business/service with price range, area served, and topic expertise.

10. **Service schema**
    - Defines the actual bookable service: mobile event planner, themed build workshop, dispensary pop-up, retail activation, private party event.

11. **Event schema**
    - Makes the site easier for search engines to understand as an offline bookable event/show/workshop.

12. **FAQ schema**
    - Adds structured Q&A around free shows, pricing, booking, custom themes, and safety/legal clarity.

13. **Breadcrumb schema**
    - Helps search engines understand homepage hierarchy.

14. **WebSite schema with SearchAction**
    - Gives the website its own searchable entity structure.

15. **Mississippi city service-area section**
    - Adds Oxford, Batesville, Grenada, Jackson, Brandon, Tupelo, Starkville, Hattiesburg, Gulfport, Biloxi, and Southaven signals.

16. **Event-planner language added above the fold**
    - The homepage clearly says Pixie's Pantry is an event planner available to be booked in Mississippi.

17. **Free-show partner pitch clarified**
    - The page explains partner value, host requirements, and why the free show is case-by-case.

18. **Internal links added to core pages**
    - Homepage links to Pricing, Themes, Deposits, Quote, Regular Pricing, and Mississippi anchor content.

19. **Search-term section added in visible copy**
    - The exact direct search phrases are visible on the page in a useful, transparent way.

20. **Sitemap and robots.txt included**
    - Helps crawlers discover all pages and confirms sitemap location.
